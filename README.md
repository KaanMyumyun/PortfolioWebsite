# Kaan Myumyun - Personal Portfolio

A clean, responsive, and minimalistic personal portfolio website to showcase my projects, skills, and experience as a Backend and DevOps Developer.

**[Live Demo: View the Portfolio Here](https://kaanmyumyun.github.io/PortfolioWebsite/)**

## Features

* **Dark/Light Mode:** Integrated theme toggler that saves user preference.
* **Fully Responsive:** Mobile-first design that looks great on all devices (phones, tablets, and desktops).
* **Working Contact Form:** Allows visitors to easily get in touch.
* **Performance Optimized:** Fast loading times using semantic HTML, pure CSS, and vanilla JavaScript.

## Built With

* **HTML5** - Semantic structure and SEO optimization.
* **CSS3** - Custom styling, Flexbox/Grid layouts, and CSS variables for theme switching.
* **Vanilla JavaScript** - For theme toggling, mobile menu navigation, and form handling.

## Running Locally

To run this project locally, you do not need any complex build tools or dependencies.

1. Clone the repository:

    git clone https://github.com/kaanmyumyun/PortfolioWebsite.git

2. Navigate to the project directory:

    cd PortfolioWebsite

3. Simply open `index.html` in your favorite web browser.
